# EKFNet

## Usage
1. Clone this repo
```
git clone https://github.com/yourusername/EKFNet.git
cd EKFNet
```
2. Download dataset from https://www.repository.cam.ac.uk/bitstreams/1cd2b04b-ada9-4841-8023-8207f1f3519b/download 

3. Download weights from https://vision.in.tum.de/webarchive/hazirbas/poselstm-pytorch/places-googlenet.pickle

4. Update paths to labels (.csv file), images, and weights in the main_local file

5. Train model

6. Test model
